## 文件命名规范

```
单元/[场景描述][耗时][得分].mp4
例：固定床/反应器超温25秒99.5.mp4
```

命名里同时编码**耗时**与**得分**两个指标，因此文件名本身就是一条数据记录，
可直接用 `scripts/parse_logs.py` 批量解析成 `data/scenarios.csv`。

## 归档原则

1. **按单元分目录**，不按时间分——复盘时按单元回看，不按日期回看
2. **场景名保留原始故障/操作描述**，不做简化，便于检索
3. **耗时与得分写进文件名**，避免额外的台账维护
4. 同类场景的多次尝试用 `_1` `_2` 后缀区分，保留失败记录
